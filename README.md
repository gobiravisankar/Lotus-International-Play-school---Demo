## Installation


```text
index.html
```

or deploy using GitHub Pages.

---

## GitHub Pages Deployment

### Step 1

Push code to GitHub.

### Step 2

Open:

Settings → Pages

### Step 3

Under Source:

```text
Deploy from branch
```

### Step 4

Select:

```text
Branch: main
Folder: /root
```

### Step 5

Save.

Your website will be available at:

```text
https://yourusername.github.io/repository-name/
```
